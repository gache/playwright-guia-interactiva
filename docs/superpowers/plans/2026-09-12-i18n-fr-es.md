# FR/ES i18n Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add French as a second language for the Playwright guide app, switchable via a sidebar control, with the choice persisted in `localStorage` and the guide's full content (sections, exercises, glossary, roadmap) plus all UI chrome translated.

**Architecture:** Content is split into parallel per-locale data modules (`src/data/es/*.ts`, `src/data/fr/*.ts`) with identical shape/order/ids — `src/types.ts` and every content-consuming component are unchanged. A `LocaleContext` holds the active locale (detected from `localStorage` → browser language → Spanish fallback) and is read directly via `useLocale()` wherever chrome text or content needs to switch. UI chrome text moves to a new `src/data/strings.ts` dictionary keyed by locale.

**Tech Stack:** Vite, React 18, TypeScript, Vitest + React Testing Library (all already in place — no new dependencies).

**Spec:** `docs/superpowers/specs/2026-09-11-i18n-fr-es-design.md`

## Global Constraints

- Section/exercise/quiz `id` values must be byte-identical between `data/es/*` and `data/fr/*` — `useProgress` persists progress by id, and switching locale mid-session must not lose or duplicate progress.
- `src/types.ts` does not change — no per-field `{es, fr}` objects; locale is selected at the array level via `getSections(locale)` etc.
- No runtime fallback for missing/mismatched translations — a structural mismatch between `es` and `fr` data must fail the extended `dataIntegrity.test.ts`, not degrade silently.
- HTML structure inside translated strings (`<code>`, `<strong>`, etc.) is preserved exactly; only text nodes and code-comment text change.
- All existing tests must keep passing unmodified in behavior (only import paths change where files moved).

- [ ] **Step 4: Implement `src/context/LocaleContext.tsx`**

```tsx
import { createContext, useContext, useState } from 'react';
import type { ReactNode } from 'react';
import type { Locale } from '../types';

const STORAGE_KEY = 'lang';
const VALID_LOCALES: Locale[] = ['es', 'fr'];

function detectInitialLocale(): Locale {
  try {
    const stored = localStorage.getItem(STORAGE_KEY);
    if (stored && (VALID_LOCALES as string[]).includes(stored)) {
      return stored as Locale;
    }
  } catch {
    // localStorage unavailable (private browsing, blocked) — fall through
  }
  return navigator.language?.toLowerCase().startsWith('fr') ? 'fr' : 'es';
}

interface LocaleContextValue {
  locale: Locale;
  setLocale: (locale: Locale) => void;
}

const LocaleContext = createContext<LocaleContextValue | undefined>(undefined);

export function LocaleProvider({ children }: { children: ReactNode }) {
  const [locale, setLocaleState] = useState<Locale>(detectInitialLocale);

  function setLocale(next: Locale) {
    setLocaleState(next);
    try {
      localStorage.setItem(STORAGE_KEY, next);
    } catch {
      // localStorage unavailable — locale still switches for this session
    }
  }

  return (
    <LocaleContext.Provider value={{ locale, setLocale }}>
      {children}
    </LocaleContext.Provider>
  );
}

export function useLocale(): LocaleContextValue {
  const ctx = useContext(LocaleContext);
  if (!ctx) throw new Error('useLocale must be used within a LocaleProvider');
  return ctx;
}
```

- [ ] **Step 6: Write `src/components/LanguageSwitcher.tsx`**

```tsx
import { useLocale } from '../context/LocaleContext';
import { strings } from '../data/strings';
import type { Locale } from '../types';

const LOCALES: { code: Locale; label: string }[] = [
  { code: 'es', label: 'ES' },
  { code: 'fr', label: 'FR' },
];

export function LanguageSwitcher() {
  const { locale, setLocale } = useLocale();
  return (
    <div className="lang-switcher" role="group" aria-label={strings[locale].languageLabel}>
      {LOCALES.map(({ code, label }) => (
        <button
          key={code}
          type="button"
          className={`lang-switcher-btn${locale === code ? ' active' : ''}`}
          aria-pressed={locale === code}
          onClick={() => setLocale(code)}
        >
          {label}
        </button>
      ))}
    </div>
  );
}
```
